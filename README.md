# pc-arch-dotfiles
Kind of realised I need a backup of my linux system, due to custom cosmetics and configs, hence git.

Goal of this is to have:
- backups of main .configs (waybar, hyprland, vim, terminal,...)
- list of AUR and other packages installed aswell as version for easy replication

- a way to automatically upload a list of packages
- a command or program to install said packages.

- steps to configure the dotfiles on a new system
